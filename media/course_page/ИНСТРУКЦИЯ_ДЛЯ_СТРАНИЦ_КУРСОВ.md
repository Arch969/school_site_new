# Как добавлять новую страницу курса

Рабочая схема сайта:

1. Материалы курса лежат в `media/course_page/<course_slug>/`.
2. Для курса нужны:
   - `hero.webp` — картинка в hero-блок;
   - `1.*`, `2.*`, `3.*`, `4.*` — изображения для секций “почему курс” и “проекты”;
   - `описание.md` — тезисы и тексты для смысловых блоков.
3. HTML-блоки страницы лежат в `src/blocks/` отдельным набором:
   - `<number>-<slug>-header.html`
   - `<number>-<slug>-hero.html`
   - `<number>-<slug>-plan.html`
   - `<number>-<slug>-why.html`
   - `<number>-<slug>-softskills.html`
   - `<number>-<slug>-projects.html`
4. В `scripts/build.mjs` нужно:
   - добавить массив `<slug>HtmlOrder`;
   - добавить preload hero-изображения;
   - собрать `blocks/css/js`;
   - создать `buildPreview` с bodyClass `ku-page ku-page--<slug>`;
   - записать страницу в корень сайта и в `dist/`.
5. В `src/css/12-scratch.css` нужно добавить новый bodyClass в общие селекторы курсов:
   - фон страницы;
   - активное подчёркивание меню;
   - отступы секции проектов;
   - разделители в meta проекта;
   - активную ссылку курса в футере.
6. На мобильной версии секции “почему курс” изображения не должны обрезаться. Для страниц курсов в `12-scratch.css` должен работать общий мобильный стиль:
   - строки секции сужаются и центрируются;
   - изображения внутри карточек используют естественную пропорцию;
   - не использовать `object-fit: cover`, если из-за этого режется важная часть изображения.
7. В блоке программы (`<number>-<slug>-plan.html`) не писать служебные подзаголовки и фразы о происхождении программы: “План курса взят из...”, “по материалам...”, “из программы Cyberum...”. На странице должен быть только полезный текст для родителей и детей.
8. В `src/blocks/03-courses.html` нужно заменить ссылку “Подробнее” у карточки курса на новую страницу.
9. В футерах `src/blocks/11-footer.html` и `src/blocks/12-scratch-footer.html` нужно добавить или обновить ссылку на страницу курса.
10. После изменений запустить `npm run build`.
11. Проверить:
   - корневой файл `<slug>.html` создан;
   - `dist/<slug>.html` создан;
   - в странице нет битых ссылок на изображения;
   - hero корректно выглядит на desktop и mobile;
   - изображения в мобильной секции “почему курс” не обрезаются.

Не редактировать сгенерированные корневые HTML вручную. Правки вносить в `src/blocks`, `src/css`, `src/js` и запускать сборку.
